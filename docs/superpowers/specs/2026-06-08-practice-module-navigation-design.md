# 练习页模块化导航设计

日期：2026-06-08

## 背景

阶段 2 当前练习页直接展示全部具体素材，例如“咖啡店点单”“办公室白板讨论”。当素材库扩展后，这个页面会变成混杂题目列表，用户难以先选择训练方式，也不利于后续为每个训练类型添加随机练习、难度筛选和搜索。

## 目标

将练习页改成“核心功能模块 → 模块内素材 → 具体练习”的结构。本次先实现前两层：

- 第一层只展示核心功能模块。
- 第二层展示所选模块下的素材。
- 选择素材后展示任务详情和录音区。

## 模块范围

本次纳入两个阶段 2 模块：

- 情境对话：包含情境脚本素材。
- 看图描述：包含图片描述素材。

`starter` 继续作为旧历史记录兼容类型保留在复盘筛选中，但不作为当前练习页模块展示。

## 行为设计

- 进入练习页时，默认显示模块卡片，不直接显示具体素材。
- 点击“进入情境对话”后，只显示情境对话素材。
- 点击“进入看图描述”后，只显示看图描述素材。
- 点击“返回模块”回到模块首页，并清除当前素材选择。
- 选择具体素材后，展示任务详情、录音控件和保存按钮。
- 保存录音时继续写入选中素材的 `taskType` 和 `taskId`。

## 验收标准

- 默认练习页可看到“情境对话”“看图描述”模块。
- 默认练习页不直接展示“咖啡店点单”“办公室白板讨论”等具体素材。
- 进入某个模块后，只展示该模块素材。
- 选择素材并保存后，保存参数仍包含正确的 `taskType` 和 `taskId`。
- 现有复盘筛选、录音防重复保存、旧 `starter` 兼容不回归。
